# ZetaEngine 反射系统梳理

## 概述
ZetaEngine 的反射系统是一个基于编译时元数据生成的类型系统，支持类、结构体、枚举、属性、函数的运行时反射。系统提供了属性编辑、序列化、克隆、引用收集等核心功能，是引擎编辑器集成和数据驱动的基石。

## 核心组件

### 1. 宏系统 (`meta_core.h:32-46`)
反射系统通过一组宏来标记需要反射的类型和成员：

| 宏 | 作用 | 编译时行为 |
|----|------|------------|
| `CLASS(...)` | 标记反射类 | 添加 `annotate("meta_class", ...)` 属性 |
| `STRUCT(...)` | 标记反射结构体 | 添加 `annotate("meta_struct", ...)` 属性 |
| `ENUM(...)` | 标记反射枚举 | 添加 `annotate("meta_enum", ...)` 属性 |
| `PROPERTY(...)` | 标记反射属性 | 添加 `annotate("meta_property", ...)` 属性 |
| `FUNCTION(...)` | 标记反射函数 | 添加 `annotate("meta_function", ...)` 属性 |
| `META(...)` | 标记枚举项 | 添加 `annotate("meta_enum_item", ...)` 属性 |

**条件编译**：当 `__META_BUILDER__` 定义时，宏添加 Clang/GCC 的属性注解，供元数据生成器解析；否则展开为空。

### 2. 属性标志 (`meta_core.h:106-124`)
```cpp
enum EPropertyFlags : uint8_t
{
    None = 0,
    EditAnywhere = 1 << 1,        // 编辑器可编辑
    VisibleAnywhere = 1 << 2,     // 编辑器可见但不可编辑
    BlueprintReadOnly = 1 << 3,   // 蓝图只读
    BlueprintReadWrite = 1 << 4,  // 蓝图读写
};
```
- 使用 `DEFINE_ENUM_FLAGS` 宏生成位运算操作符
- 标志互斥处理：`VisibleAnywhere` 会移除 `EditAnywhere`，`BlueprintReadWrite` 会移除 `BlueprintReadOnly`

### 3. 属性关键字 (`meta_core.h:79-104`)
`PROPERTY` 宏支持的关键字参数：
- `DisplayName` - 自定义显示名称
- `Category` - 属性分类（默认 "Default"）
- `OnChanged` - 属性变化回调函数
- `ClampMin` / `ClampMax` - 数值范围限制
- `Delta` - 拖动步进值
- `Shader` - 生成 Shader 使用的结构体
- `CallInEditor` - 编辑器可调用函数

### 4. 生成宏 (`meta_core.h:126-179`)
- `GENERATED_BODY_PLAIN(CLASS_NAME)` - 为普通类型添加反射支持
- `GENERATED_BODY(CLASS_NAME)` - 为 Object 派生类添加反射支持，包含构造函数辅助

生成的内容包括：
- 静态元信息指针 `s_meta_info`
- 属性访问方法 `get_property` / `set_property`
- 方法调用 `invoke`
- 类型名访问 `get_static_type_name`

## 属性系统

### 1. 属性基类 (`PropertyBase`)
抽象基类，定义所有属性的通用接口：

**容器类型** (`EContainerType`)：
- `Primitive` - 标量类型
- `Vector` - 向量容器
- `Map` - 映射容器
- `Set` - 集合容器
- `Enum` - 枚举类型

**核心方法**：
- `clone()` / `clone_element()` - 深度克隆
- `collect_references()` - 收集对象引用（用于垃圾回收）
- `collect_weak_references()` - 收集弱引用
- `on_serialize()` - 序列化支持
- `get_container_pointer()` - 获取容器指针
- `callback()` - 属性变化回调

### 2. 标量属性 (`Property<T>`)
处理基本数据类型、对象指针和结构体：

**特性**：
- 支持 `IsObjectPointer`、`IsStructType` 类型检测
- 自动处理对象指针的引用收集
- 支持数值范围的 `clamp_min` / `clamp_max` / `delta` 限制
- 对象指针变化时触发 `CoreObjectDelegates::on_object_property_changed`

**模板参数**：
- `GetterType` - 成员获取函数
- `ConstGetterType` - 常量成员获取函数
- `SetterType` - 成员设置函数
- `raw_setter` - 反序列化专用设置器

### 3. 枚举属性 (`EnumProperty<T>`)
专门处理枚举类型：

**特性**：
- 通过全局 `g_enum_helpers` 映射获取枚举元数据
- 支持枚举值与显示名称的转换
- 提供 `get_enum_item_names()` 获取所有枚举项
- 提供 `set_enum_by_name()` 通过名称设置枚举值

### 4. 容器属性
#### Vector 容器 (`VectorProperty<T>`)
支持 `TVector<T>`（引擎自定义向量容器）：

**功能**：
- 元素访问 `get_element_at()`
- 元素修改 `modify_element()`
- 元素删除 `remove_element_at()`
- 清空 `clear()` 和添加 `add_element()`
- 容器大小 `get_container_size()`

#### Map 容器 (`MapProperty<Key, Value>`)
支持 `TMap<Key, Value>`（引擎自定义映射容器）：

**功能**：
- 键列表 `get_map_keys()`
- 值访问 `get_map_value()`
- 键修改 `modify_map_key()`（支持对象指针变化通知）
- 值修改 `modify_map_value()`
- 键值对删除 `remove_map_value()`
- 键指针管理 `copy_key_ptr()` / `delete_key_ptr()`

#### Set 容器 (`SetProperty<T>`)
支持 `TSet<T>`（引擎自定义集合容器）：

**功能**：
- 集合操作：添加、清空、获取大小
- 元素引用收集支持

**容器共同特性**：
- 嵌套容器支持（Vector of Vector, Map of Vector 等）
- 深度克隆和引用收集
- 元素级回调机制

## 元信息管理

### MetaInfo 类 (`meta_core.h:1380-1514`)
存储类型的完整反射信息：

**数据结构**：
```cpp
class MetaInfo {
    std::unordered_set<MetaInfo*> bases;      // 基类元信息
    std::string type_name;                    // 类型名称
    std::map<std::string, PropertyBase*> properties;  // 属性映射
    std::unordered_map<std::string, FunctionInfo> functions;  // 函数映射
    int member_size = 0;                      // 可见成员数量
};
```

**继承关系**：
- 支持多重继承
- 缓存所有基类 (`all_bases_cache`) 优化派生关系检测
- 提供 `is_derived_from()` 和 `is_base_of()` 方法

**属性访问**：
- 递归查找属性（支持继承链）
- 类型安全的 `get_property<T>()` 和 `set_property<T>()`
- 容器指针获取 `get_pointer_property()`

**函数调用**：
- 支持可变参数的方法调用
- 参数包装 `ArgumentWrapper` 处理引用和值类型
- 递归查找函数实现

**其他功能**：
- 深度克隆 `clone()`
- 引用收集 `collect_references()`
- 弱引用收集 `collect_weak_references()`
- 成员计数 `get_member_size()`

## 克隆系统

### 对象克隆 (`meta_core.cpp:52-100`)
```cpp
void* clone_object(void* original_object, bool filter_assets = true);
```

**流程**：
1. 检查克隆缓存 `g_cloned_ids`（避免重复克隆）
2. 过滤资产对象（`Asset` 派生类不克隆，返回原指针）
3. 通过类工厂 `g_class_factories` 创建新实例
4. 递归克隆所有属性
5. 调用 `on_load()` 初始化新对象
6. 记录到克隆映射表

### 结构体克隆
```cpp
void clone_struct(void* original_struct, void* target_struct);
```

**流程**：
1. 获取结构体的 `MetaInfo`
2. 递归克隆所有属性

### 值克隆模板 (`meta_core.h:400-434`)
```cpp
template<typename T> T clone_value(T& element, PropertyBase* element_property = nullptr);
```

**类型分发**：
- 对象指针 → `clone_object()`
- 结构体 → `clone_struct()`
- 容器（Vector/Map/Set）→ `PropertyBase::clone_element()`
- 普通值 → 直接复制

## 序列化支持

### 属性序列化
每个属性类实现 `on_serialize()` 方法：
- 保存时：获取当前值并序列化
- 加载时：反序列化值并设置（使用 `raw_setter`）

### 序列化字段宏
使用 `SERIALIZE_FIELD(ar, name, value)` 宏处理不同类型：
- 普通类型：直接序列化
- 支持 `serialize_asset()` 方法的类型：调用自定义序列化

## 引用收集系统

### 强引用收集
用于垃圾回收和依赖分析：

**流程**：
1. 对象指针属性：收集指针指向的对象
2. 结构体属性：递归收集成员引用
3. 容器属性：遍历元素收集引用
4. 避免重复收集（性能优化）

### 弱引用收集
用于弱引用管理系统（当前为空实现，可扩展）

## 使用示例

### 1. 定义反射类
```cpp
CLASS("DisplayName=MyClass", Category="Gameplay")
class MyClass : public Object {
    GENERATED_BODY(MyClass)
    
    PROPERTY(DisplayName="Health", Category="Stats", ClampMin=0, ClampMax=100)
    float health = 100.0f;
    
    PROPERTY(Category="Inventory")
    TVector<Item*> inventory;
    
    FUNCTION(Category="Actions", CallInEditor)
    void Attack();
};
```

### 2. 运行时反射使用
```cpp
// 获取属性值
float health = obj->get_property<float>("health");

// 设置属性值
obj->set_property("health", 75.0f);

// 调用方法
obj->invoke("Attack");

// 检查类型关系
if (obj->get_meta_info()->is_derived_from(Character::s_meta_info)) {
    // 是Character派生类
}

// 克隆对象
MyClass* cloned = static_cast<MyClass*>(clone_object(original));
```

### 3. 编辑器集成
```cpp
// 遍历所有可编辑属性
for (auto& [name, property] : meta_info->properties) {
    if (property->has_flags(EPropertyFlags::EditAnywhere)) {
        // 在属性窗口中显示编辑控件
        render_property_editor(property);
    }
}
```

## 架构特点

### 1. 编译时与运行时结合
- 编译时：宏标记生成元数据注解
- 构建时：元数据生成器解析注解生成注册代码
- 运行时：通过全局表查找元信息

### 2. 类型安全
- 模板化的属性访问方法
- 编译时类型检测
- 运行时类型验证

### 3. 性能优化
- 继承关系缓存
- 引用收集去重
- 按需克隆（资产对象不克隆）

### 4. 扩展性
- 插件式属性类型
- 自定义容器支持
- 可扩展的序列化机制

### 5. 编辑器友好
- 属性分类和显示名称
- 数值范围验证
- 变化回调通知
- 蓝图系统集成

## 依赖关系

1. **核心对象系统**：依赖 `Object` 和 `Class` 基类
2. **字符串工具**：使用 `StringUtil` 进行字符串处理
3. **容器系统**：依赖 `TVector`、`TMap`、`TSet` 容器
4. **序列化系统**：依赖 `Archiver` 和 `SERIALIZE_FIELD` 宏
5. **委托系统**：使用 `CoreObjectDelegates` 发送属性变化通知

## 注意事项

1. **线程安全**：反射系统目前不是线程安全的，应在主线程使用
2. **内存管理**：`MetaInfo` 和属性对象需要正确清理
3. **循环引用**：克隆系统通过 `g_cloned_ids` 避免循环引用
4. **资产处理**：资产对象默认不克隆，保持引用原对象
